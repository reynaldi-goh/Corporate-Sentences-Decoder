# Corporate Sentence Decoder 🕴️➡️🗣️

Ever read a LinkedIn post and wonder, "What are they actually trying to say?"

A two-player game where one player writes a sentence in corporate jargon and the other 
tries to guess the plain-English translation (or vice versa). Powered by AI for instant, 
on-the-fly translations between corporate buzzword-speak and blunt human language.

## How to Play
1. Pick a direction: LinkedIn ➜ Human, or Human ➜ LinkedIn
2. Enter a sentence and hit **Decode**
3. Hide the result and challenge a friend to guess it
4. Reveal to see how close they got

## Tech Stack
- Next.js (App Router, JavaScript)
- Tailwind CSS
- Groq API
